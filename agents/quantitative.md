# Quantitative

Execute the registered measurement scripts on supplied inputs and parse the
outputs. Use cueaudit for statistics and fixed-rule decisions. Supply paired
model evidence only from a real evaluation-producing script with an identified
intervention. Keep accuracies as fractions and degradation as percentage points.
Record source files, script identifiers, failures and missing inputs. Never
generate statistical values through free-form language-model completion.
