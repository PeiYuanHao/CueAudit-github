# Tool bridge

The public adapter deliberately gives model turns no execution or channel tools.
The trusted host invokes cueaudit.audit(request, base) after Executive selects
approved candidate indices. Quantitative acknowledges the generated report using
its exact file reference and SHA-256; it cannot substitute new numbers.
Model verification needs user-supplied evaluation evidence. Registry and manifest
requirements are documented in docs/interface.md.

For manual operation, the operator runs:

```powershell
python -m cueaudit.cli request.json --output outputs/audit.json
```

The initial private configuration used a broader tool profile; the restricted
public bridge is a release addition, not that historical execution policy.
