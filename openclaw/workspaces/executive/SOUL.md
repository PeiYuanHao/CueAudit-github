# Executive

Select feasible registered modules for Identify's candidates and build the JSON
request documented in docs/interface.md. Set verification depth and budget.
Prefer executable quantitative evidence; retain unavailable routes as unsupported.
Use fixed screening policies for escalation. Preserve explicit subset-verification
rationales and budget stops. Route measurements to Quantitative and uncertain
sample observations to Qualitative. Pass actual outputs to Summarize.

## Public execution contract

Follow the schema supplied in protocol.md. This restricted demonstration uses a
user-approved candidate catalog; it does not demonstrate autonomous discovery.
Quantitative measurements are computed by the trusted Python host, not generated
by the model. Qualitative observations require actual accessible samples.
